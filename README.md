# 荒路一碗 / Souplife

路还没有修好，饭可以先做好。

《荒路一碗》是一款以末日旅途和房车泡面摊为主题的慢节奏经营原型。听客人讲一段路上的故事，准备食材，把握一锅面的火候，再把热饭端到窗口。这里没有顾客耐心倒计时。

本仓库保存中文主工程，内容对应 2026 年 9 月 13 日的“厨房与猎场”版本。工程内部仍保留“末日泡面摊 V4”的名称和版本目录命名。

## 开始运行

1. 安装 **Godot 4.7.2**。
2. 在 Godot 项目管理器中导入仓库根目录的 [`project.godot`](project.godot)。
3. 等待首次资源导入完成，按 **F5** 运行整个项目。
4. 推荐使用鼠标，窗口至少为 **1280 × 800**。

项目使用 GL Compatibility 渲染器，无需另外安装插件。若使用 F6，请先打开 `main.tscn`；F6 只运行当前场景，单独运行 `房车场景.tscn` 不会呈现完整游戏。

## 当前可玩内容

- **一锅五格的料理**：选汤味、备菜、切肉、烧水、撕袋、下面，按不同食材的熟度要求依次投料；五格走满后自动盛面。
- **顾客与故事**：三个停靠点、九位顾客、对话分支、评价、换餐与有条件的纪念品赠礼。
- **每天的经营安排**：完成当地当天的顾客名单后收摊，再安排旅行、外卖和狩猎；商店在营业期间也可补货。
- **食材与收纳**：培养皿种植、浇水再生、顶柜背包、冰箱冷藏、区域商品与设备升级。
- **三地区猎场**：沙地嫩掌蜥与稀有红掌蜥、响石岩坡的岩兔、白盐浅滩的泽鸭；开镜射击、弹仓升级、自动收获和每日有限猎物。
- **旅途氛围**：缓慢变化的天气与昼夜、灶台录音拟音、四首程序编曲与软件音色合成的循环音乐。

这是可继续开发的可玩原型。人物使用有限帧的状态动作，地图与外卖通过菜单推进，尚未扩展为自由行走或完整长篇剧情。

详细操作见 [试玩指南](docs/PLAY_GUIDE.md)。世界观设计见 [设定存档](docs/WORLD.md)，其中后续构想不代表已实现玩法。

## 工程结构

| 位置 | 内容 |
|---|---|
| `main.tscn` / `scripts/main.gd` | 游戏入口、模块组合、料理阶段、光照与存档 |
| `房车场景.tscn` | 可编辑的基础 3D 画片场景 |
| `scripts/` | 厨房、顾客、故事、每日经营、商店、狩猎、音频与验收脚本 |
| `shaders/` | 像素画片、色键抠图、天气、汤面与猎场效果 |
| `assets/` | 图片、GLB 画片、音频、字体及来源记录 |
| `docs/` | 操作、素材来源与世界观文档 |
| 	ests/ | 当前界面、教程与猎场验收入口 |

游戏采用 3D 正交画片、低分辨率子视口和像素贴图。部分物件、UI 与动画由脚本在运行时创建，因此以 F5 运行效果为准。资源旁的 `.import` 设置和 `.uid` 应随源码保留；`.godot/` 是首次导入时重建的本地缓存。

## 存档与导出

游戏自动保存到 Godot 用户数据目录中的 `stall_save_v4.json`，该存档不放在源码仓库里。桌面版与网页版分别保存进度。

Windows 导出预设名为 `Windows Desktop`。首次导出需在 Godot 中安装对应版本的导出模板，再在“项目 → 导出”中选择该预设。导出前先创建 `build/windows` 文件夹；输出为 `build/windows/Souplife.exe`。可执行文件与同名 `.pck` 应放在一起分发。

`scripts/verify*.gd` 保留各阶段的自动验收代码；部分历史断言已被新规则替代，不应将全部旧脚本的结果合并为当前版本的测试结论。当前推荐入口、隔离输出位置与本次结果见 [验收说明](tests/README.md)。
