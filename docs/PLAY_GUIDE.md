# 荒路一碗 · 试玩指南

对应 2026-09-13“厨房与猎场”中文版本。

## 开始一段旅程

用 Godot 4.7.2 导入根目录的 `project.godot`，等待资源导入后按 F5。首次新旅程会由机器人小满逐步介绍操作；已有存档可以选择继续。推荐使用鼠标和至少 1280×800 的窗口。

## 慢慢做一碗面

1. **听点单。** 客人到窗口后会打招呼，点击客人查看订单与聊天。对话、口味和火候会共同影响部分赠礼条件。
2. **选择汤味并备料。** 准备时可选牛肉、海鲜或蔬菜味，对应浓褐、白色和橙色汤底。悬停食材查看需要的火候。整肉上砧板切三刀，再点一下备妥；采下的菜会叠放在台面。
3. **烧水与下面。** 点锅烧水。水开后点桌上面袋撕开，再点一次让面饼和调料下锅。面饼和调料实际落锅时，固定五格计时才开始。
4. **依次投料。** 每格约四秒。按食材需要的火候决定什么时候下锅；鸡蛋先敲壳，蛋液落锅后才计熟度，可以提前约一秒操作。
5. **自动盛面，再端给客人。** 五格走满后自动关火盛面，成品先留在自己的台面。点击成品、拖到客人面前，或点“端到窗口长板”出餐。客人吃一口后才评价、付款；道别后下一位到来。

| 食材示例 | 最佳火候 | 参考投料时机 |
|---|---|---|
| 牛肉、普通蜥肉、红掌蜥肉 | 五格 | 下面后尽快下锅 |
| 鸡蛋、响石岩兔肉 | 四格 | 走完一格时下锅 |
| 午餐肉、盐帆泽鸭肉 | 三格 | 走完两格时下锅 |
| 卷心菜、菠菜 | 两格 | 走完三格时下锅 |
| 香菜、葱段 | 一格 | 走完四格时下锅 |

其他食材以游戏内悬停提示为准。锅里最多四种主食材，调味料不占位；台面可暂存六份备料。已经备好但尚未入锅的食材可右键收回，或拖回原位置。已经下锅的食材不再退还。查看背包、帮助、冷藏或纪念品等弹窗时，料理计时暂停。

全部入锅食材都达到最佳火候时，会出现完美料理的星光与弹跳，小满也会赞叹。赠礼还需要符合点单、对话与剧情条件；火候完美并不保证每位客人都会送礼。普通但合口味的面也会得到“好吃”的评价。

## 种菜、冷藏与收纳

- 培养皿从上到下是香菜、卷心菜、菠菜、小葱。收获后，空培养皿浇一次水便开始再生。
- 悬停或点击冰箱可打开上半扇门。三地区特殊鲜肉放在冷藏层；需要切片的肉先上砧板。
- 顶柜显示背包和纪念品。点击纪念品可再看特写；已经送给其他角色的剧情物品会实际消耗。
- 垃圾桶平时关闭，拖成品面靠近才开盖。丢弃料理不会返还已经下锅的食材。

## 今天营业，今晚出发

旧公路营地每天有老乔、禾苗、拾风、阿砾、白禾五位顾客；铁轨哨站和盐湖渡口每天各两位。同一天的名单不会循环出现，拒绝换餐后离开的拾风也算来过。

需要接待完所在区域当天的全部顾客，才能结束营业。最后一位离开后，窗口保持无人状态；点击“结束今天营业”，再安排狩猎、外卖或旅行。换区域不会立即开始新的一天。准备好后，点击机器人下方日期屏，主动选择“开始下一天”。

左侧分别是地图、商店、外卖和打猎。接待客人时也可以进入商店采购、补水；外出活动需要等收摊。各区域的商品和补给不同。外卖按订单做面、打包，再出发送达，不设交付倒计时。

拾风会提出用旧站铜鸟哨换餐，可以接受或拒绝。其他纪念品要满足人物自己的剧情与料理条件；它们不是每次到访都能重复领取的奖励。

## 三处猎场

| 停靠点 | 猎场 | 主要猎物 |
|---|---|---|
| 旧公路营地 | 沙地猎场 | 嫩掌蜥，偶尔出现红掌稀有个体 |
| 铁轨哨站 | 响石岩坡 | 响石岩兔 |
| 盐湖渡口 | 白盐浅滩 | 盐帆泽鸭 |

进入猎场时先在原房车视角看窗外风景后移，停车后才推近窗口。右键或空格开镜，左键射击；需要开镜才能命中。默认弹仓六发，打空后自动换弹，也可按 R 提前换弹。商店可升级到八发、十发弹仓。

猎物倒地后，掉落食材会自动飞回库存，无需手动拾取。当天每个地区的猎物数量有限；全部逃走或被打倒后，再次进入不会刷新，第二天才出现新一批。稀有红掌蜥并非每次都会出现。按 Esc 可返回房车，返回不会自动推进日期。

## 声音、画面与存档

| 按键 | 用途 |
|---|---|
| M | 静音 / 恢复声音 |
| F11 | 切换全屏 |
| F1 | 查看 3D 画片层次 |
| W / T | 预览天气 / 时段 |
| Esc | 关闭部分菜单；猎场中返回 |

声音菜单可分别调节操作声、环境声和音乐。游戏自动保存物资、地区、故事、纪念品及经营进度。桌面版与网页版使用各自的存档；首次网页交互后才能播放音频。

没有顾客耐心倒计时。烧水、烹饪、种植和换弹有各自的短动画时间，可以按自己的节奏游玩。
